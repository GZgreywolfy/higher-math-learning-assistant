## 测试用例 1：C9 工科（极高难度）

**输入**：
- 院校：浙江大学
- 专业：计算机科学与技术
- 时间节点：高考后暑假初期（6月底）

**期望输出结构**：
1. 院校分析：识别为 C9 联盟 → Tier 1+（分值：5）
2. 专业分析：工科 → 高数A（系数：1.0），触发 WebSearch 检索培养方案
3. 综合难度评分：5 × 1.0 = 5.0 → **极高**
4. 试卷检索：检索浙大高数试卷，标注可信度
5. 学习计划：4-5 个阶段，每日 2-3 小时
6. 资源推荐：同济版 + 吉米多维奇 + 历年真题
7. 附 MIT 学习法指南
8. 附免责声明

- 时间节点：暑假初期（6月）

1. **模糊输入澄清**：AI 应引导用户提供具体院校名称

   - 使用 Tier 3（普通本科）作为默认档位
   - 在结论中标注"基于默认估算"

4. 综合难度评分：2 × 1.0 = 2.0 → **较低（估算）**
5. 所有输出标注"基于默认值"的说明

## 测试用例 8：在读期间同步辅导（反馈闭环）

**输入**：
- 院校：武汉大学
- 专业：电子信息工程
- 场景：已读到大二上学期，高数上期期末考了 72 分，希望补救和提升
- 时间节点：寒假期间

**期望输出结构**：
1. 院校分析：985 → Tier 1（分值：4）
2. 专业分析：工科 → 高数A（系数：1.0）
3. 综合难度评分：4 × 1.0 = 4.0 → **高**
4. 试卷检索：检索武大高数试卷，分析题型分布
5. **反馈闭环触达**：
   - AI 应引导用户反馈已掌握和薄弱的章节
   - 根据反馈动态调整补救计划
   - 例如：用户已掌握极限和导数，但积分薄弱 → 重点补习积分部分
6. 学习计划：分阶段补救计划，从薄弱环节切入
7. MIT 方法：强调费曼技巧用于查漏补缺
8. 附免责声明

## 测试通过标准

每个测试用例通过的条件：
- [ ] AI 正确识别院校层次和难度档位
- [ ] AI 正确判断专业对应的高数级别
- [ ] 综合难度评分计算正确
- [ ] WebSearch 调用位置合理（培养方案、试卷检索）
- [ ] 输出包含完整的个性化学习方案
- [ ] 可信度标注正确（基于检索结果或默认值）
- [ ] 包含免责声明
- [ ] 输出格式与 SKILL.md 模板一致
