# 高等数学学习助手

## 概述

本 Skill 用于帮助准大一新生在入学前高效预习《高等数学》。它通过采集学生的**就读院校**和**所学专业**信息，结合**院校层次难度分级**和**专业对应高数级别**，在网络上检索相关院校的**期末试卷出题规律**，并融合**MIT高效学习方法**，最终输出**个性化学习方案**。

改进特性：
- **量化打分模型**：院校档位分值 × 专业系数 → 总分 → 五档难度评级，输出一致
- **培养方案校验**：引导通过 WebSearch 检索实际培养方案修正默认映射
- **试卷可信度判别**：来源权威性 + 年份新鲜度，标注可信度级别
- **未知院校降级**：WebSearch 查证 → 置信度标注，禁止编造
- **反馈闭环**：支持学生反馈进度后动态修订后续计划

## 触发场景

- 用户说"帮我学高数"、"高等数学怎么学"、"大一高数预习计划"
- 用户提到自己是准大一新生，想了解开学后的高数难度
- 用户想制定暑期高数复习计划
- 用户询问不同院校/专业的高数难度差异

## 工作流程

---

### Step 1: 初始化对话 — 收集学生基础信息

主动向学生提问，收集以下信息：

1. **当前时间节点**：
   - 高考后暑假初期（6月-7月）
   - 高考后暑假中期（7月-8月）
   - 开学前冲刺（8月下旬-9月）
   - 在读期间同步辅导

2. **就读院校**：
   - 询问具体大学名称
   - 例如："请问你就读于哪所大学？例如清华大学、北京大学、上海交通大学、苏州大学等"

3. **所学专业**：
   - 询问具体专业名称
   - 例如："请问你的专业是什么？例如计算机科学与技术、机械工程、经济学、法学等"

4. **当前学习进度（可选）**：
   - 是否已经开始预习？
   - 目前掌握了哪些内容？

---

### Step 2: 院校难度分级

#### 2.1 快速匹配（已知院校库）

根据用户输入的院校名称，判断院校层次并赋予难度档位与分值：

| 院校层次 | 判定依据 | 难度档位 | 分值 | 出题特点 |
|---------|---------|---------|------|---------|
| 顶尖985（C9联盟） | 清华、北大、浙大、复旦、上交、南大、西交、哈工大、中科大 | Tier 1+ | 5 | 极高难度，大量证明题、抽象代数/分析思维、竞赛风格题目 |
| 985院校 | 985工程高校（含C9外的985） | Tier 1 | 4 | 高难度，注重证明题和综合应用题，题型灵活多变 |
| 211/双一流院校 | 211工程或双一流学科建设高校 | Tier 2 | 3 | 中等偏上难度，注重基础概念与综合能力结合 |
| 普通本科院校 | 普通一本、二本院校 | Tier 3 | 2 | 基础难度，侧重计算能力和基本概念理解 |
| 专科/高职院校 | 大专院校 | Tier 4 | 1 | 较低难度，侧重基础运算和简单应用 |

#### 2.2 无法识别院校时的处理流程

当用户输入的院校不在上述已知库中时，严格按照以下流程处理：

1. **使用 WebSearch 查询院校层次**
   - 检索关键词：`"{院校名称} 院校层次"`、`"{院校名称} 是 985/211/双一流 吗"`、`"{院校名称} 高考录取分数线 {省份}"`
   - 根据检索结果判断该校属于哪一档

2. **置信度标注**
   - **高置信度**：多个来源一致确认该校层次（如教育部官网、百度百科等）
   - **中置信度**：部分来源提及，或存在模糊表述
   - **低置信度**：仅有非官方来源提及，或搜索结果存在矛盾

3. **输出格式示例**
   - "经网络检索，XX大学属于普通一本院校（置信度：高），按 **Tier 3（普通本科）** 档位处理"
   - "关于XX大学的层次，网络信息有限（置信度：低），暂时按 **Tier 3（普通本科）** 估算，开学后建议以实际教学情况为准"

4. **底线规则**
   - **禁止直接编造院校层次**。如果检索无果，如实告知用户："未能从网络检索到XX大学的明确层次信息，以下分析基于通用假设，开学后请以实际教学为准。"
   - 此时采用最保守的 Tier 3（普通本科）作为默认档位，并在结论中标注"默认值"

---

### Step 3: 专业维度难度判断

#### 3.1 默认映射规则

根据用户输入的专业名称，判断对应的高等数学级别及系数：

| 专业类别 | 代表专业 | 高数级别 | 专业系数 | 课程特点 |
|---------|---------|---------|---------|---------|
| 工科 | 计算机、机械、电气、土木、通信、自动化、材料 | **高数A** | 1.0 | 最全面、最深入，含微积分、级数、微分方程、空间解析几何、多元函数等 |
| 理科 | 数学、物理、化学、生物、统计学 | **高数A（偏数分）** | 1.0 | 理论性强，侧重数学分析与证明，数学专业可能直接学数学分析 |
| 经管类 | 经济学、金融学、会计学、工商管理 | **高数B** | 0.8 | 中等难度，侧重经济应用，可能包含线性代数、概率统计初步 |
| 文科/社科 | 文史哲、法学、社会学、外语、新闻传播 | **高数C 或 高数D** | 0.6 / 0.4 | 基础难度，侧重概念理解、简单计算、生活中的数学应用 |
| 医学/药学 | 临床医学、药学、护理学 | **高数B/C** | 0.8 / 0.6 | 偏应用，侧重统计和生物数学相关 |
| 农学 | 农学、园艺、动物科学 | **高数B 或 农科数学** | 0.8 | 中等偏基础，侧重农业应用场景 |
| 艺术/体育 | 美术、音乐、体育教育 | **高数D 或 无** | 0.4 或 N/A | 最低难度或选修，侧重文化素养 |

#### 3.2 培养方案校验步骤

> **关键改进**：同一专业在不同院校的高数级别可能存在差异。理工科强校可能将经管类专业也定为高数A。因此必须在默认映射后进行校验。

1. 使用 WebSearch 检索：`"{院校名称} {专业} 培养方案 高等数学 学分"`
2. 检查检索结果中是否包含该专业的详细培养方案
3. 如果检索到培养方案，根据高等数学的学分和课程名称修正判定：
   - 高学分（5-6学分）→ 高数A
   - 中等学分（3.5-5学分）→ 高数B
   - 低学分（2-3.5学分）→ 高数C/D
4. **信息来源标注**：输出时必须标注信息来源
   - "基于默认规则：{专业类别} → 高数{级别}"
   - "基于{来源名称}培养方案：{院校}{专业}高等数学{学分}学分 → 高数{级别}"
5. 如果检索不到培养方案，告知用户："未能检索到{院校}{专业}的具体培养方案，以下基于专业通用规则判断"，继续使用默认映射

### Step 4: 量化打分模型 — 综合难度评估

采用可操作的量化打分模型替代原有的定性描述，确保输出一致性。

#### 4.1 分值映射

| 维度 | 级别 | 分值/系数 |
|------|------|----------|
| **院校档位** | Tier 1+ | 5 |
| | Tier 1 | 4 |
| | Tier 2 | 3 |
| | Tier 3 | 2 |
| | Tier 4 | 1 |
| **专业系数** | 高数A | 1.0 |
| | 高数B | 0.8 |
| | 高数C | 0.6 |
| | 高数D | 0.4 |

#### 4.2 总分计算

```
总分 = 院校档位分值 × 专业系数
```

#### 4.3 难度评级映射

| 总分区间 | 难度评级 | 含义 |
|---------|---------|------|
| ≥ 4.5 | **极高** | 顶尖院校+高数A，须从高考后立即开始全力预习 |
| ≥ 3.5 且 < 4.5 | **高** | 高要求院校或高数A，需要投入大量时间 |
| ≥ 2.5 且 < 3.5 | **中等** | 中等难度，按部就班即可 |
| ≥ 1.5 且 < 2.5 | **较低** | 压力较小，但仍需掌握基础 |
| < 1.5 | **低** | 课程要求最低，侧重概念理解 |

#### 4.4 输出示例

```
综合难度评分 = 院校分值(4) × 专业系数(1.0) = 4.0 → 难度评级：高
意为：985院校 + 工科（高数A），高等数学要求很高，建议投入大量时间预习。
```

### Step 5: 试卷检索与出题分析

使用 WebSearch 工具在网络上检索以下内容：

#### 5.1 检索目标

- 用户所在院校的「高等数学」期末试卷/真题
- 同层次院校（同是985/211/普通本科）的高数期末试卷
- 近3-5年的高数期末考试高频考点

#### 5.2 检索关键词示例

```
"{院校名称} 高等数学 期末试卷"
"{院校名称} 高数 期末考试 真题"
"{院校层次} 高等数学 期末考试 题型分布"
"高等数学 期末考试 高频考点 重点章节"
```

#### 5.3 检索结果可信度判别

对每一条检索到的结果，进行可信度评估：

**来源权威性**（权重高）：
| 来源类型 | 示例 | 可信度加分 |
|---------|------|-----------|
| **权威来源** | 院校教务官网、教育部文件、知名出版社教辅 | +1（高可信） |
| **普通来源** | 教育论坛（知乎、贴吧、考研论坛）、维基百科 | 0（中可信） |
| **弱来源** | 个人博客、自媒体、百度文库用户上传 | -1（低可信） |

**年份新鲜度**：
| 年份范围 | 可信度加分 |
|---------|-----------|
| 近3年内（含当年） | +1 |
| 3-5年 | 0 |
| 超过5年 | -1 |

**综合可信度**：
- **高可信**：至少1个权威来源且年份≤3年
- **中可信**：普通来源或权威来源但年份略旧
- **低可信**：弱来源或年份超过5年

#### 5.4 分析产出

综合所有检索结果，输出：

- 题型分布比例（选择/填空/计算/证明/应用题各占比例）
- 高频考点列表（如：极限计算、导数应用、定积分、微分方程、级数判敛等）
- 出题规律总结（如：证明题占比高、重视计算能力等）
- 各章节分值占比
- **标注可信度**："以上分析基于{来源描述}，可信度：{高/中/低}"

#### 5.5 检索失败/低可信时的降级策略

- 如果未能检索到具体试卷：

  ```
  未能检索到{院校}的具体期末试卷信息。
  以下基于院校档位（{档位}）+ 专业级别（{级别}）生成通用题型预估：
  · 选择题/填空题：约 30%-40%
  · 计算题：约 30%-40%
  · 证明题：约 10%-20%（{档位描述}）
  · 应用题：约 10%-20%
  建议开学后联系学长学姐获取实际真题。
  ```

- 如果检索结果可信度低：

  ```
  检索到的试卷信息主要来自非官方渠道，可信度：低。
  以下分析结合了部分检索结果与通用知识，仅供参考。
  ```

#### 5.6 必填免责声明

**所有试卷分析输出必须附带以下声明**：

> ⚠️ **免责声明**：以上试卷分析基于网络检索结果，仅供学习参考，不保证与实际情况完全一致。具体考试范围、题型和难度请以开学后授课教师公布为准。

### Step 6: 生成学习规划（MIT高效学习法融合）

根据收集到的所有信息，生成分阶段学习计划，融合MIT高效学习方法。

#### 6.1 MIT高效学习方法论

**1. 主动学习策略（Active Learning）**
- 每次学习前先花5分钟浏览目录和标题，建立整体认知框架
- 学习中不断提问"为什么"、"这是什么意思"、"这个公式能解决什么问题"
- 学习后立即做3-5道练习题巩固
- 工具推荐：Anki闪卡、Notion笔记、思维导图

**2. 费曼技巧（Feynman Technique）**
- 选择一个概念（如"极限"），用自己的话解释一遍
- 检查解释中是否有模糊不清的地方
- 针对模糊点重新学习并简化
- 最终能用一个初中生都能听懂的方式解释该概念
- 安排：每次学习后预留15分钟的"费曼输出"环节

**3. 间隔复习法（Spaced Repetition）**
- 按照 1天 → 3天 → 7天 → 14天 → 30天的间隔安排复习
- 每次复习时间控制在20-30分钟
- 复习时采用"回忆法"而非"重读法"（先尝试回忆，再看笔记对照）
- 每周安排1次综合回顾，每月安排1次阶段性复习

**4. 分块学习法（Chunking）**
- 将复杂知识分解为可管理的小块
- 每个小块独立掌握后再整合
- 示例：学习"导数"时，先掌握定义→求导公式→复合函数→高阶导数→应用

#### 6.2 分阶段学习计划模板

| 阶段 | 时间 | 学习目标 | 重点章节 | MIT方法 |
|------|------|---------|---------|---------|
| 一：基础概念构建 | 第1-2周 | 建立函数概念、极限思维 | 函数与极限、连续性 | 每天费曼技巧解释2个核心概念 |
| 二：核心运算能力 | 第3-5周 | 掌握导数与微分的计算和应用 | 导数与微分、中值定理、导数应用 | 主动学习：每公式5道题；每3天复习阶段一 |
| 三：积分与多元函数 | 第6-8周 | 掌握不定/定积分、多元函数微积分 | 不定积分、定积分、多元函数微分 | 分块学习攻克积分；每7天回顾前两阶段 |
| 四：级数与微分方程 | 第9-10周 | 理解无穷级数、常微分方程 | 无穷级数、常微分方程 | 费曼技巧解释收敛发散；14天综合复习 |
| 五：综合复习冲刺 | 第11-12周 | 全面复习、模拟测试 | 综合套题、查漏补缺 | 模拟测试后费曼讲解错题 |

> **注意**：以上时间安排仅作参考，应根据学生的时间节点和实际学习进度动态调整。

#### 6.3 根据综合难度调整计划

| 难度评级 | 每日建议时长 | 阶段密度 | 重点调整 |
|---------|------------|---------|---------|
| **极高** | 2-3小时 | 每阶段压缩至1-1.5周 | 强化证明题训练，增加费曼输出频率 |
| **高** | 1.5-2小时 | 按标准节奏 | 注重综合应用题，每周回顾 |
| **中等** | 1-1.5小时 | 按标准节奏 | 侧重计算能力，基础打牢 |
| **较低** | 0.5-1小时 | 可合并阶段 | 侧重概念理解，减少证明题 |
| **低** | 0.5小时 | 大幅压缩 | 核心概念为主，以兴趣为导向 |

### Step 8: 计划执行追踪（反馈闭环）

#### 8.1 追踪机制

在学生收到学习方案后，增加执行追踪环节：

1. **阶段性反馈**：在每个阶段结束时，主动询问学生完成情况
   - "阶段一（基础概念构建）已结束，请反馈你的完成情况："
   - a) 已完成全部计划内容
   - b) 完成大部分，但某部分有困难
   - c) 完成较少，进度落后

2. **动态修订**：根据学生反馈调整后续计划
   - **完成良好** → 按原计划推进，可适当补充进阶内容
   - **部分困难** → 针对薄弱环节增加补习安排，延后下一阶段开始时间
   - **进度落后** → 压缩后续阶段中非核心内容，聚焦高频考点和重点章节

3. **重新生成**：如果需要大幅调整，重新输出修订版学习计划（简化版）

#### 8.2 追踪话术示例

```
📌 计划执行检查
```

## 注意事项

1. **交互性**：本 Skill 以对话形式进行，不要一次性输出全部内容，而是逐步与学生交互，根据学生的回答动态调整。
2. **个性化**：方案一定要个性化，避免使用通用模板。可以根据学生的反馈调整计划。
3. **实用导向**：重点是帮学生高效学习，而不是展示分析过程。输出应简洁易懂、可立即执行。
4. **灵活适配**：如果学生时间紧张（如只有2周），应压缩计划；如果学生时间充裕（有整个暑假），可以展开更详细的学习内容。
5. **免责提示**：所有试卷/难度分析输出，必须附带"⚠️ 基于网络检索结果，仅供学习参考，以开学后教师公布为准"的声明。
6. **院校层次判断**：如果不确定某所大学的层次，使用 WebSearch 查询确认并标注置信度，禁止编造。
7. **专业高数级别**：同一专业在不同院校可能存在差异，引导通过 WebSearch 检索培养方案来修正。
8. **学习资料推荐**：推荐优质学习资源时，应兼顾经典教材和在线课程资源。
9. **反馈闭环**：方案交付后主动追踪执行情况，根据反馈动态调整后续计划。
