# 高等数学学习助手 Skill 规格文档

## Why
帮助准大一新生在入学前高效预习《高等数学》，根据院校层次、专业要求和学习阶段自动定制个性化学习方案，融合MIT高效学习方法提升学习效果。

## What Changes
- 创建高等数学学习助手 Skill（SKILL.md），具备以下六大核心功能模块：
  1. **学习规划引擎**：根据学生当前学习阶段和时间节点，自动生成阶段性学习计划
  2. **院校信息采集与难度分级**：交互询问就读院校，按985/211/双一流/普通本科分级
  3. **试卷检索与出题参考**：网络检索目标院校或同层次院校的高数期末试卷，分析高频考点
  4. **专业维度难度判断**：询问所学专业，判断高数课程难度级别（高数A/B/C）
  5. **MIT高效学习法融合**：整合主动学习、费曼技巧、间隔复习等方法
  6. **综合输出**：生成包含重点章节优先级、练习题推荐、复习时间表的个性化方案
- 创建配套的 MCP 工具或辅助脚本用于试卷检索（WebSearch）
- 将代码推送到 GitHub 仓库

## Impact
- Affected specs: Trae Skill 系统
- Affected code: `高等数学学习助手skill/` 目录下的 SKILL.md 及相关辅助文件

## ADDED Requirements

### Requirement: 学习规划引擎
The system SHALL 根据学生当前时间节点（如高考后暑假、开学前一个月等）自动生成阶段性学习计划。

#### Scenario: 暑假预习阶段
- **WHEN** 学生选择暑假预习模式
- **THEN** 生成包含基础概念梳理、重点章节预习、习题训练的三阶段计划，每阶段明确时间跨度、学习目标和复习安排

### Requirement: 院校信息采集与难度分级
The system SHALL 通过交互询问学生的就读院校，依据院校层次判断期末考试出题难度。

#### Scenario: 985院校
- **WHEN** 学生输入985院校名称
- **THEN** 系统判定为最高难度档位（Tier 1），出题难度大，注重证明题和综合应用题

#### Scenario: 211/双一流院校
- **WHEN** 学生输入211或双一流院校名称
- **THEN** 系统判定为中等难度档位（Tier 2），注重基础与综合能力

#### Scenario: 普通本科院校
- **WHEN** 学生输入普通本科院校名称
- **THEN** 系统判定为基础难度档位（Tier 3），侧重计算能力和基本概念

### Requirement: 试卷检索与出题参考
The system SHALL 根据学生院校信息，在网络上检索该校或实力相近院校的高等数学期末试卷。

#### Scenario: 成功检索
- **WHEN** 系统通过 WebSearch 检索到目标院校或同层次院校的试卷信息
- **THEN** 综合分析题型分布（选择/填空/计算/证明）、高频考点和出题规律，作为学习重点参考

#### Scenario: 检索失败
- **WHEN** 系统未能检索到具体试卷
- **THEN** 依据院校难度档位和专业要求，生成通用的题型分布预估和高频考点推荐

### Requirement: 专业维度难度判断
The system SHALL 通过询问学生所学专业，判断其高等数学课程难度级别。

#### Scenario: 工科专业
- **WHEN** 学生输入工科专业（如计算机、机械、电气等）
- **THEN** 判断为高数A（最高难度），侧重微积分、级数、微分方程等深度内容

#### Scenario: 理科专业
- **WHEN** 学生输入理科专业（如数学、物理、化学等）
- **THEN** 判断为高数A（较高难度），侧重理论证明与数学分析思维

#### Scenario: 经管类专业
- **WHEN** 学生输入经济、管理类专业
- **THEN** 判断为高数B（中等难度），侧重经济数学应用

#### Scenario: 文科/社科专业
- **WHEN** 学生输入文史哲、法学等专业
- **THEN** 判断为高数C或高数D（较低难度），侧重基础概念和简单应用

### Requirement: MIT高效学习法融合
The system SHALL 将MIT高效学习方法融入学习规划中。

#### Scenario: 主动学习策略
- **THEN** 规划中包含课前预习→课堂主动参与→课后即时复习的闭环策略

#### Scenario: 费曼技巧
- **THEN** 每次学习后安排"费曼输出"环节，要求学生用自己的话复述概念

#### Scenario: 间隔复习法
- **THEN** 按照 1天→3天→7天→14天→30天的间隔安排周期性复习节点

### Requirement: 综合输出
The system SHALL 综合上述所有维度，输出个性化学习方案。

#### Scenario: 完整输出
- **THEN** 输出包含以下内容：
  - 院校难度评级及说明
  - 专业对应高数级别及学习侧重
  - 试卷分析结果（或预估）
  - 分阶段学习计划（含时间表）
  - 重点章节优先级排序
  - 练习题推荐方向
  - MIT学习法实践指南
