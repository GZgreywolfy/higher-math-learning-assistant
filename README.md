> 帮助准大一新生在入学前高效预习《高等数学》，根据院校层次、专业要求和学习阶段自动定制个性化学习方案，融合 MIT 高效学习方法提升学习效果。

## 项目简介

本项目是一个 **Trae IDE Skill**，旨在为即将进入大学的新生提供个性化的《高等数学》学习规划服务。通过采集学生的**就读院校**和**所学专业**信息，结合**院校层次难度分级**和**专业对应高数级别**，在网络上检索相关院校的**期末试卷出题规律**，并融合**MIT高效学习方法**，最终输出**个性化学习方案**。

### 前置依赖

- Trae IDE（需支持 Skill 功能）
- AI 模型需支持 WebSearch 工具调用（用于检索院校培养方案、期末试卷等信息）
- 不同 AI 模型的检索能力可能存在差异，建议使用支持联网搜索的模型

### 核心特性

- **量化打分模型** — 院校档位分值 × 专业系数 → 总分 → 五档难度评级，输出一致
- **内置院校-专业知识库** — JSON 内置库优先匹配 50+ 院校和 40+ 专业，未命中走 WebSearch
- **培养方案校验** — 通过 WebSearch 检索实际培养方案修正默认专业-高数级别映射
- **试卷可信度判别** — 来源权威性 + 年份新鲜度标注可信度级别
- **未知院校降级** — WebSearch 查证 → 置信度标注，禁止编造
- **MIT 方法落地映射** — 四种方法论映射为具体可执行动作（输出练习、复述挑战、间隔复习、分块学习）
- **学习效果评估与动态调优** — 2 周后自动出诊断题，按正确率分流继续/复习/重学
- **反馈闭环** — 支持学生反馈进度后动态修订后续计划

## 如何导入使用

### 在 Trae IDE 中使用

1. 克隆本仓库到本地工作目录：
   ```bash
   git clone https://github.com/GZgreywolfy/higher-math-learning-assistant.git
   ```

2. 在 Trae IDE 中打开该项目目录。

3. 当用户输入以下触发词时，Skill 将自动激活：
   - "帮我学高数"
   - "高等数学怎么学"
   - "大一高数预习计划"
   - "我是 XX 大学 XX 专业，高数怎么学"

4. Skill 激活后，AI 将按照 SKILL.md 中定义的 8 步流程交互式地收集信息并输出个性化方案。

### 验证 Skill 是否生效

在 Trae IDE 中打开项目后，输入以下任一触发词：
- "帮我学高数"
- "高等数学怎么学"

如果 AI 按照 SKILL.md 中定义的 8 步流程（收集信息 → 院校分级 → 专业判断 → 量化打分 → 试卷检索 → 学习规划 → 综合输出 → 反馈追踪）响应，则说明 Skill 已成功加载。

## 功能模块说明

| 模块 | 功能描述 |
|------|---------|
| **学习规划引擎** | 根据学生当前时间节点自动生成阶段性学习计划 |
| **院校难度分级** | 按 C9/985/211 双一流/普通本科/专科五档判断，未知院校支持 WebSearch 查证 |
| **试卷检索参考** | 网络检索目标院校或同层次院校的高数期末试卷，分析题型分布和高频考点 |
| **专业难度判断** | 按工科/理科/经管/文科/医学/农学/艺术等判断高数级别（A/B/C/D） |
| **MIT 高效学习法** | 融合主动学习策略、费曼技巧、间隔复习法、分块学习法 |
| **学习效果评估** | 学习 2 周后自动出诊断题，按正确率分流继续/复习/重学，动态调优 |
| **计划执行追踪** | 支持学生反馈进度，动态修订后续阶段计划 |

## 如何贡献

我们欢迎各种形式的贡献！具体方式包括：

### 提交新的院校-专业-高数级别映射数据

如果你了解某所院校某个专业的高数级别信息，且不在现有映射规则覆盖范围内，欢迎提交：

1. 在 [Issues](https://github.com/GZgreywolfy/higher-math-learning-assistant/issues) 中创建新 Issue，标题格式为 `[映射数据] 院校名称 - 专业名称`
2. 提供以下信息：
   - 院校全称及层次（C9/985/211/普通本科/专科）
   - 专业全称
   - 该专业对应的高数级别（A/B/C/D）及学分
   - 信息来源（如：培养方案截图链接、教务官网链接等）
3. 我们核实后会更新到默认映射规则中

### 提交 Bug 或功能建议

请先检查现有 Issues 中是否已有相关讨论，如果没有则创建新的 Issue。

### 提交 Pull Request

请参考 [CONTRIBUTING.md](./CONTRIBUTING.md) 中的详细指引。
