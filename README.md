# 高等数学学习助手 Skill

> 帮助准大一新生在入学前高效预习《高等数学》，根据院校层次、专业要求和学习阶段自动定制个性化学习方案，融合 MIT 高效学习方法提升学习效果。

---

## 项目简介

本项目是一个 **Trae IDE Skill**，旨在为即将进入大学的新生提供个性化的《高等数学》学习规划服务。通过采集学生的**就读院校**和**所学专业**信息，结合**院校层次难度分级**和**专业对应高数级别**，在网络上检索相关院校的**期末试卷出题规律**，并融合**MIT高效学习方法**，最终输出**个性化学习方案**。

### 核心特性

- **量化打分模型** — 院校档位分值 × 专业系数 → 总分 → 五档难度评级，输出一致
- **培养方案校验** — 通过 WebSearch 检索实际培养方案修正默认专业-高数级别映射
- **试卷可信度判别** — 来源权威性 + 年份新鲜度标注可信度级别
- **未知院校降级** — WebSearch 查证 → 置信度标注，禁止编造
- **反馈闭环** — 支持学生反馈进度后动态修订后续计划
- **MIT 高效学习法** — 融入主动学习、费曼技巧、间隔复习等方法论

## 如何导入使用

### 在 Trae IDE 中使用

1. 克隆本仓库到本地工作目录：
   ```bash
   git clone https://github.com/GZgreywolfy/higher-math-learning-assistant.git
   ```

2. 在 Trae IDE 中打开该项目目录。

3. 当用户输入以下触发词时，Skill 将自动激活：
   - "帮我学高数"
   - "高等数学怎么学"
   - "大一高数预习计划"
   - "我是 XX 大学 XX 专业，高数怎么学"

4. Skill 激活后，AI 将按照 SKILL.md 中定义的 8 步流程交互式地收集信息并输出个性化方案。

### 示例对话：985 工科（极高难度）

```
用户：我今年高考完了，想预习一下高等数学。我是浙江大学的，计算机专业。

AI：你好！让我来帮你制定个性化高数预习计划。
首先确认一下时间：你现在是暑假初期还是已经到暑假中期了？

用户：刚考完没多久，现在6月底。

AI：好的。让我先分析你的情况——

📊 院校分析：浙江大学 → C9顶尖985 → Tier 1+（分值：5）
📖 专业分析：计算机 → 工科 → 高数A（系数：1.0）
📐 综合难度评分：5 × 1.0 = 5.0 → 【极高】难度

[检索培养方案、试卷信息...]

═══════════════════════════════════════════
  高等数学个性化学习方案
═══════════════════════════════════════════
· 院校：浙江大学（C9顶尖985）
· 专业：计算机科学与技术（高数A）
· 综合难度评分：5.0 → 极高
· 每日建议时长：2-3小时
· 重点：极限与连续 → 中值定理证明 → 定积分 → 级数 → 微分方程
· MIT方法：费曼技巧 + 间隔复习 + 主动学习
═══════════════════════════════════════════
```

### 示例对话：普通本科经管（较低难度）

```
用户：我考上了苏州科技大学，会计学专业。高数难吗？

AI：苏州科技大学 → 普通本科 → Tier 3（分值：2）
会计学 → 经管类 → 高数B（系数：0.8）
综合难度评分：2 × 0.8 = 1.6 → 【较低】难度

整体压力不大，按部就班学习即可，侧重经济数学应用。
```

### 示例对话：985 文科（中等难度）

```
用户：我是北京师范大学的，汉语言文学专业，要学高数吗？

AI：北京师范大学 → 985院校 → Tier 1（分值：4）
汉语言文学 → 文科 → 高数C（系数：0.6）
综合难度评分：4 × 0.6 = 2.4 → 【中等】难度

虽是文科专业，但北师大作为985院校对通识要求较高，不能掉以轻心。
建议掌握基础概念和简单运算，无需做偏题怪题。
```

## 功能模块说明

| 模块 | 功能描述 |
|------|---------|
| **学习规划引擎** | 根据学生当前时间节点（暑假初期/中期/开学前/在读）自动生成阶段性学习计划 |
| **院校难度分级** | 按 C9/985/211 双一流/普通本科/专科五档判断出题难度，未知院校支持 WebSearch 查证 |
| **试卷检索参考** | 网络检索目标院校或同层次院校的高数期末试卷，分析题型分布和高频考点 |
| **专业难度判断** | 按工科/理科/经管/文科/医学/农学/艺术等判断高数级别（A/B/C/D） |
| **MIT 高效学习法** | 融合主动学习策略、费曼技巧、间隔复习法、分块学习法 |
| **计划执行追踪** | 支持学生反馈进度，动态修订后续阶段计划 |
