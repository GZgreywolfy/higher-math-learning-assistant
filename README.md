# 高等数学学习助手 Skill

帮助准大一新生在入学前高效预习《高等数学》，根据院校层次、专业要求和学习阶段自动定制个性化学习方案，融合MIT高效学习方法提升学习效果。

## 功能
- **学习规划引擎**：根据时间节点自动生成阶段性学习计划
- **院校难度分级**：按985/211/双一流/普通本科分级判断出题难度
- **试卷检索参考**：网络检索目标院校或同层次院校的高数期末试卷
- **专业难度判断**：按工科/理科/经管/文科等判断高数级别（A/B/C/D）
- **MIT高效学习法**：融合主动学习、费曼技巧、间隔复习等方法
- **综合输出**：生成个性化学习方案（含重点优先级、练习推荐、复习时间表）

## 使用
当用户提到"高等数学"、"高数"、"大一数学预习"等相关内容时，AI 将自动触发此 Skill。
