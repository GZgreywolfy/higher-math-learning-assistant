# 量化评分模型

> 本文档详细说明高等数学学习助手的评估体系，包括院校档位分值、专业系数以及综合评分的难度评级映射。

---

## 院校档位分值表

| 院校层次 | 档位 | 分值 | 说明 |
|---------|------|------|------|
| C9 联盟 | Tier 1+ | 5 | 清华、北大、浙大、复旦、上交、南大、中科大、哈工大、西交 |
| 985 工程（非 C9） | Tier 1 | 4 | 其他 985 院校 |
| 211 / 双一流 | Tier 2 | 3 | 211 工程或双一流建设高校 |
| 普通本科 | Tier 3 | 2 | 普通一本、二本院校 |
| 专科 / 高职 | Tier 4 | 1 | 大专院校及高等职业技术学院 |

### 院校分级说明

- **C9 联盟 (Tier 1+, 5分)**：中国顶尖大学联盟，高数教学难度最高，考试中证明题和综合题占比显著高于其他院校
- **985 工程 (Tier 1, 4分)**：非 C9 的 985 院校，教学和考试难度较高，注重理论基础和综合应用
- **211 / 双一流 (Tier 2, 3分)**：国家重点建设高校，教学难度中等偏上
- **普通本科 (Tier 3, 2分)**：普通本科院校，教学侧重基础概念和计算能力
- **专科 / 高职 (Tier 4, 1分)**：以职业技能培养为主，高数要求最低，侧重基础运算

### 未知院校处理规则

1. 优先在 `institutions.json` 内置库中匹配
2. 未命中 → 通过 WebSearch 检索院校层次
3. WebSearch 也无结果 → 采用 Tier 3（普通本科）作为默认值
4. 所有基于默认值的结果均标注"默认值（检索不可用）"

## 专业系数表

| 专业类别 | 高数级别 | 系数 | 代表专业 |
|---------|---------|------|---------|
| 工科 | 高数 A | 1.0 | 计算机、机械、电子、土木、自动化 |
| 理科 | 高数 A | 1.0 | 数学、物理、化学、统计学 |
| 经管类 | 高数 B | 0.8 | 金融、会计、经济学、工商管理 |
| 文科 / 社科 | 高数 C | 0.6 | 法学、外语、新闻、社会学 |
| 医学 / 药学 | 高数 B/C | 0.8 / 0.6 | 临床医学、药学、护理学 |
| 农学 | 高数 B/C | 0.8 / 0.6 | 农学、林学、园艺 |
| 艺术 / 体育 | 高数 D / 无 | 0.4 / N/A | 美术、音乐、舞蹈、体育 |

### 专业系数说明

- **工科 / 理科 (系数 1.0)**：高数 A 级别，课时最多（通常 5-6 学分），要求全面掌握微积分、级数、微分方程等内容，证明题要求高
- **经管类 (系数 0.8)**：高数 B 级别，课时中等（通常 4-5 学分），侧重经济数学应用，如边际分析、弹性分析、最优化问题
- **文科 / 社科 (系数 0.6)**：高数 C 级别，课时较少（通常 3 学分），以概念理解和基础运算为主，证明题极少
- **医学 / 药学 (系数 0.8/0.6)**：因院校而异，部分院校要求高数 B，部分为高数 C，侧重统计学基础和生物数学
- **农学 (系数 0.8/0.6)**：因院校而异，部分院校要求高数 B，部分为高数 C
- **艺术 / 体育 (系数 0.4/N/A)**：高数 D 级别或无高数要求，以文化素养和基础数学概念为主

### 未知专业处理规则

1. 优先在 `major-mapping.json` 内置库中匹配
2. 未命中 → 基于专业类别通用规则判断
3. 培养方案校验 → WebSearch 检索 `"{院校} {专业} 培养方案 高等数学 学分"` 修正默认映射
4. 检索无结果 → 使用默认映射，标注"未检索到培养方案"

## 综合评分与难度评级

### 计算公式

```
综合评分 = 院校分值 × 专业系数
```

### 五档难度评级映射

| 综合评分范围 | 难度评级 | 学习建议 |
|------------|---------|---------|
| ≥ 4.5 | **极高** | 建议高考后立即开始预习，每日 2-3 小时，准备证明题训练 |
| 3.5 ~ 4.5（不含 4.5） | **高** | 建议暑假系统预习，每日 1.5-2.5 小时，注重综合题型 |
| 2.5 ~ 3.5（不含 3.5） | **中等** | 建议暑假选择性预习，每日 1-1.5 小时，侧重基础章节 |
| 1.5 ~ 2.5（不含 2.5） | **较低** | 基础预习即可，每日 0.5-1 小时，侧重概念理解 |
| < 1.5 | **低** | 少量预习即可，每日 0.5 小时，了解基本概念 |

### 评级示例

| 院校 + 专业 | 分值 | 系数 | 评分 | 难度 |
|------------|------|------|------|------|
| 浙江大学 + 计算机（C9 工科） | 5 | 1.0 | 5.0 | 极高 |
| 武汉大学 + 电子信息（985 工科） | 4 | 1.0 | 4.0 | 高 |
| 上海财经大学 + 金融（211 经管） | 3 | 0.8 | 2.4 | 较低 |
| 苏州科技大学 + 机械（普通本科工科） | 2 | 1.0 | 2.0 | 较低 |
| 某职业技术学院 + 电商（专科经管） | 1 | 0.8 | 0.8 | 低 |

### 综合评级说明

- **极高难度 (≥4.5)**：C9 院校的工科/理科专业，需要投入最大精力
- **高难度 (3.5~4.5)**：985 院校核心专业或 C9 院校非核心专业
- **中等难度 (2.5~3.5)**：211/双一流院校核心专业或 985 院校文科专业
- **较低难度 (1.5~2.5)**：普通本科院校或 211 院校文科/艺术专业
- **低难度 (<1.5)**：专科院校或低系数专业组合，基本压力很小

## 培养方案校验机制

即使通过内置库或通用规则得到了默认的高数级别映射，系统仍会通过 WebSearch 检索目标院校的实际培养方案进行校验：

1. **检索关键词**：`"{院校} {专业} 培养方案 高等数学 学分"`
2. **结果判定**：
   - 检索成功 → 采用实际培养方案中的高数级别和学分
   - 检索失败 → 使用默认映射，标注"未检索到培养方案"
3. **来源标注**：所有检索结果均标注信息来源和可信度

## 试卷检索与可信度评估

### 可信度评分

| 维度 | 加分项 | 扣分项 |
|------|-------|-------|
| 来源权威性 | 教务官网 (+1) | 论坛 (0) | 博客 (-1) |
| 年份新颖度 | 近 3 年内 (+1) | 3-5 年 (0) | 超 5 年 (-1) |

### 综合判定

| 总得分 | 可信度级别 |
|-------|-----------|
| ≥ 1 | 高 |
| 0 | 中 |
| ≤ -1 | 低 |

### 降级处理

- 检索失败 → 基于院校档位 + 高数级别生成通用题型预估
- 可信度低 → 标注"非官方渠道，仅供参考"
- 所有分析必须附带免责声明
